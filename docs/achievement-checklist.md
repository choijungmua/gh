# GitHub achievement checklist

This checklist focuses on legitimate work. GitHub describes Achievements as a public
preview, so behavior may change.

| Achievement | Legitimate qualifying activity | Needs another person? |
| --- | --- | --- |
| Quickdraw | Close an issue or pull request within five minutes | No |
| Pull Shark | Have pull requests you opened merged | No for an owned repository; maintainers for external repositories |
| YOLO | Merge your own pull request without an approved review | No |
| Pair Extraordinaire | Merge a pull request containing a genuinely co-authored commit | Yes |
| Galaxy Brain | Have answers accepted in repository Q&A Discussions | Yes, for a reliable acceptance path |
| Starstruck | Reach the star threshold on one repository you created | Yes |
| Public Sponsor | Sponsor open-source work through GitHub Sponsors | Payment required |

## Healthy workflow

1. Make a real change that can be reviewed independently.
2. Preserve authorship accurately.
3. Follow branch protection and review rules.
4. Answer genuine questions with reproducible information.
5. Let stars reflect voluntary interest in the project.

Do not use fake accounts, repetitive empty pull requests, self-authored fake Q&A, or
star-for-star exchanges.
