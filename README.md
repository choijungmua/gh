# gh

A compact, bilingual lab for practicing healthy GitHub collaboration with real,
reviewable work.

GitHub의 Issue, Pull Request, co-author commit, Discussions Q&A를 정상적인 협업
흐름으로 연습하고 기록하는 공개 저장소입니다.

## Start here / 시작하기

1. Read [CONTRIBUTING.md](CONTRIBUTING.md).
2. Open an issue that describes a real documentation gap or reproducible problem.
3. Discuss the change before opening a larger pull request.
4. Keep each pull request focused and explain how it was checked.

문서의 오류 수정, 재현 가능한 예제, GitHub 협업 팁을 환영합니다. 큰 변경은 먼저
Issue 또는 Discussion에서 목적과 범위를 합의해 주세요.

## Q&A Discussions

Use the repository's **Q&A** category for genuine GitHub workflow questions. Include:

- the outcome you want;
- the commands or UI steps you tried;
- the actual result or error;
- relevant GitHub documentation.

질문에는 목표, 시도한 방법, 실제 결과를 함께 적어 주세요. 해결된 답변은 질문
작성자가 `Mark as answer`로 채택하면 다음 방문자도 빠르게 해결책을 찾을 수 있습니다.

## Collaboration principles

- Make meaningful, reviewable changes.
- Credit only people who actually contributed, using a GitHub-linked email.
- Never exchange stars, create fake accounts, or generate artificial activity.
- Respect the rules and review requirements of every repository.
