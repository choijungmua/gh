# gh

A small public repository for learning and documenting healthy GitHub collaboration workflows.

## Contributing

Useful documentation improvements, reproducible examples, and corrections are welcome. Please open an issue or discussion before proposing a larger change.

## Discussions

Use the Q&A category for genuine GitHub workflow questions. Include the goal, what you tried, and the exact result so answers remain useful to future readers.

## Collaboration principles

- Make meaningful, reviewable changes.
- Credit real collaborators with GitHub-linked co-author details.
- Do not exchange stars or create artificial activity.
- Follow the GitHub Acceptable Use Policies.
