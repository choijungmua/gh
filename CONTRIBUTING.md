# Contributing

Thanks for helping make this collaboration lab more useful.

## Good contributions

- Correct an inaccurate GitHub workflow explanation.
- Add a reproducible command or UI example.
- Improve Korean or English wording without changing the meaning.
- Link an official GitHub document that supports a claim.

## Workflow

1. Open an issue or Q&A discussion explaining the problem.
2. Create a focused branch from `main`.
3. Make one coherent change and verify every command you document.
4. Open a pull request that links the issue and describes the verification.
5. Respond to review feedback before the pull request is merged.

## Co-authored work

Use a `Co-authored-by` trailer only when another person genuinely helped create the
commit. Ask which GitHub-linked email they want to use, and obtain permission before
publishing it.

```text
Co-authored-by: Name <github-linked-email@example.com>
```

Never add a person merely to trigger profile activity.

## Conduct

Keep discussions technical and respectful. Spam, star exchanges, fake accounts, and
automated achievement farming are not accepted.
